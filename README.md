# 충남 고교 과목 선택 실습 v2

2025·2026학년도 입학생 편제표 데이터 기반 시뮬레이션 사이트.
Vanilla HTML/JS, 정적 호스팅 (서버 불필요).

## 실행

`file://`로 직접 열면 fetch가 CORS에 막히므로 로컬 서버로 띄워야 합니다:

```bash
cd site
python3 -m http.server 8080
# → http://localhost:8080
```

## v2 신규 기능

### 1. 계열 프리셋 (6종)
헤더의 프리셋 버튼 클릭 → 해당 계열에 맞는 과목 자동 선택
- **이공·자연**: 물리·화학·생명·지구과학 + 미적분·기하 + 진로 과학 + 인공지능
- **공학·IT**: 수학·물리 기반 + 정보 진로 + 프로그래밍/AI/데이터
- **경상·사회**: 확률통계·경제수학 + 경제·법·사회 + 금융과 경제생활
- **인문·어문**: 문학·독서 + 역사·윤리 + 영어 심화 + 제2외국어
- **예술**: 음악·미술 진로/융합 과목
- **체육**: 체육 진로 실기 + 보건·심리

선택 후 셀을 직접 클릭하면 프리셋이 자동 해제되고 수동 편집으로 전환됩니다.

매칭 방식: 학교가 어떤 과목을 개설했든 **과목명 키워드 매칭**으로 자동 적용.
정확 매칭 우선, 부분 매칭 보조. preset에 우선순위가 매겨져 있어 같은
계열이라도 더 핵심적인 과목이 먼저 선택됩니다.

### 2. URL 공유
헤더 우측의 "🔗 공유 링크 복사" 버튼 → 현재 학년도·학교·학과·선택 상태를
쿼리스트링에 직렬화하여 URL 복사. 링크를 받은 사람은 같은 시뮬레이션을
그대로 열어볼 수 있습니다.

### 3. 특목고 학과 통합
충남외고·충남예고·충남디자인예고·온양용화고(체육중점)·덕산고(IB) 등
학과/과정 분기가 있는 학교는 학교 선택 시 **학과 드롭다운이 추가로 나타남**.
학교 목록에서 학과를 가진 학교에는 ✦ 표시.

### 4. 그룹 헤더에 충족 상태 인라인 표시
각 선택 그룹 헤더에 충족 여부 배지를 실시간 표시.
우측 패널 보지 않아도 한눈에 어느 그룹이 미달인지 확인 가능.

## 폴더 구조

```
site/
├── index.html
├── README.md
└── data/
    ├── schools.json                 # 84개 + 학과 인덱스 (departments_2025/2026)
    ├── courseDB.json                # 834개 과목 마스터
    ├── curriculum_2025/             # 93개교 + 학과별 JSON
    ├── curriculum_2025_index.json
    ├── curriculum_2026/             # 94개교 + 학과별 JSON
    └── curriculum_2026_index.json
```
