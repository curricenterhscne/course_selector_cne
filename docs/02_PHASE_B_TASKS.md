## B-3. 학교 통합 검색

목적: 지역 드롭다운 + 학교 드롭다운 + 검색칸 3개를 **하나의 통합 검색**으로.

수행할 작업:

1. 기존 UI 제거:
   - `#region-sel` 셀렉트
   - `#school-sel` 셀렉트
   - `#school-search` 입력칸
2. 새 UI 추가 (위치: 기존 toolbar 동일 위치):
   - `<input type="text" id="school-finder" placeholder="학교명 또는 지역 입력 (예: 천안, 외고)">`
   - 입력 아래에 autocomplete 드롭다운 (`<ul id="finder-dropdown">`)
3. 동작 구현:
   - 입력 비어있으면 드롭다운 숨김
   - 1글자 이상 입력 시 매칭 학교를 드롭다운에 표시 (최대 10개)
   - 매칭 우선순위:
     1순위: 학교명이 입력으로 시작 (prefix 매치)
     2순위: 학교명에 입력 포함
     3순위: 지역에 입력 포함
   - 키보드 ↑↓로 이동, Enter로 선택, Esc로 닫기
   - 마우스 클릭으로도 선택
   - 학과 가진 학교는 항목 끝에 `✦` 표시
   - 선택 시 입력칸에 "[학교명]" 채우고 드롭다운 닫고 편제표 로드
4. 학과 드롭다운(`#dept-sel`)은 학교 선택 후 그대로 옆에 표시.
5. 스타일:
   - 드롭다운: 베이지 배경, 적색 호버, 12.5px 산세리프.
   - 기존 toolbar 톤 유지. 화려한 그림자나 애니메이션 피할 것.
   - 모바일 대응: 입력 wide, 드롭다운 input 폭에 맞춤.

검증 단계:

1. "천안" 입력 → 천안 지역 학교들이 드롭다운에 나타남
2. "외고" 입력 → 충남외국어고등학교 매칭
3. "충남디자인" 입력 → 충남디자인예술고등학교 매칭, `✦` 표시 있음
4. 키보드만으로 학교 선택 가능
5. 학교 선택 후 학과 드롭다운 정상 노출
6. 모바일 뷰(Chrome DevTools)에서 드롭다운이 화면 벗어나지 않음

## B-4. 교과군별 필수 이수학점 표시

수행할 작업:

1. `index.html` 상단에 상수 정의:
   ```js
   const REQUIRED_CREDITS = {
     '국어': 8, '수학': 8, '영어': 8, '사회': 8, '한국사': 6,
     '과학': 8, '체육': 8, '예술': 6,
   };
   const GROUPED_CATEGORY = {
     name: '기술·가정/정보/제2외국어/한문/교양',
     members: ['기술·가정', '정보', '제2외국어', '한문', '교양'],
     required: 12,
   };
   ```
   주의: A-6에서 '정보과학'을 분리했으면 그 카테고리는 `REQUIRED_CREDITS`에
   따로 추가 (필수 이수학점은 학교마다 다르므로 우선 표시 없이 둠).

2. `updateCounter()`의 group-breakdown 렌더 로직 수정:
   - 각 교과군 행에 `이수 / 필수` 형태 표시
   - 필수 미달: `--accent` 적색 + `✗`
   - 충족: `--ok` 초록 + `✓`
   - 초과: 회색 그대로 + 학점만
3. `GROUPED_CATEGORY.members`에 속한 교과군들을 합산해서 별도 한 행으로 추가
   표시. 라벨은 짧게: "기·정·외·한·교".
4. 표시 순서:
   - 주요 교과군 (국어, 수학, 영어, 사회, 한국사, 과학, 체육, 예술) 먼저
   - 정보과학 (있다면)
   - 기·정·외·한·교 합산
   - 기타 (창체는 별도이므로 여기 제외)

검증 단계:

1. 천안중앙고 + 이공·자연 추천 적용 시 교과군 충족 여부 표시 확인.
2. 일부러 한 영역 비워서(예: 영어 선택 그룹 모두 해제) `✗` 미달 표시 확인.
3. 합산 카테고리 정상 표시 확인.

⏸ **사용자 확인 필요**: 결과 보고 후 OK 받으면 B-5로.

## B-5. ★ 저장/불러오기 (이번 Phase 핵심 신기능)

목적: 학생이 시뮬레이션 결과를 로컬 파일로 보존·재개·공유.
**서버 없음. 로그인 없음. 100% 클라이언트 사이드.**

### B-5-1. UI 추가

수행할 작업:

   - JSON으로 저장 (이어서 작업하기용)

   - Excel로 저장 (재가공용)
3. 불러오기 버튼: 숨겨진 `<input type="file" accept=".json">` 트리거.
4. 드래그앤드롭 지원: 페이지 전체에 dragover/drop 리스너 달아 JSON 파일이면

검증 단계: UI가 헤더에 잘 자리잡고, 모바일에서도 깨지지 않는지.

### B-5-2. JSON 저장/불러오기 (라이브러리 불필요)

수행할 작업:

1. `exportToJSON()` 함수 작성. 다음 구조 출력:
   ```json
   {
     "schema": "cne_course_selector/v1",
     "exportedAt": "2026-05-18T14:30:00+09:00",
     "year": "2026",
     "schoolCode": "N100000246",
     "schoolName": "천안중앙고등학교",
     "department": null,
     "selections": ["g1-s0-sem2", "g1-s1-sem3", ...],
     "preset": "science",
     "summary": {
       "totalCredits": 192,
       "changcheCredits": 18,
       "groupBreakdown": { "국어": 20, "수학": 16, ... }
     }
   }
   ```
2. 파일명 자동 생성:
   `과목선택_[학교명]_[학과명 있으면]_[YYYYMMDD_HHmm].json`
   파일명에 특수문자·공백 안전 처리.
3. 다운로드 방식: Blob + URL.createObjectURL + 임시 `<a>` 클릭 트릭.

4. `importFromJSON(file)` 함수 작성:
   - FileReader로 텍스트 읽기 → JSON 파싱.
   - `schema` 필드 확인. `cne_course_selector/v1` 아니면 친절한 에러.
   - `year`가 현재와 다르면 학년도 전환.
   - `schoolCode`로 학교 로드, `department` 있으면 학과 설정.
   - `selections` 배열을 `state.userSelections`에 복원.
   - `preset` 있으면 active 상태 복원 (단, 셀 재계산은 selections 기준).
   - 토스트로 "복원 완료" 안내.
   - 에러 케이스 모두 try/catch로 친절한 알림.

검증 단계:

1. 천안중앙고 + 이공 추천 → JSON 저장 → 다른 학교 본 뒤 → JSON 불러오기 →
   천안중앙고 + 이공 상태로 복원되는지.
2. 잘못된 JSON 파일(예: 빈 객체) 업로드 → 친절한 에러 토스트.
3. 다른 학년도 JSON 업로드 → 자동 학년도 전환 후 복원.

### B-5-3. PDF 저장 (html2pdf.js 동적 로드)

수행할 작업:

1. 동적 로드 헬퍼:
   ```js
   async function ensureLibrary(globalName, url) {
     if (window[globalName]) return;
     await new Promise((res, rej) => {
       const s = document.createElement('script');
       s.src = url;
       s.onload = res;
       s.onerror = () => rej(new Error('스크립트 로드 실패'));
       document.head.appendChild(s);
     });
   }
   ```
2. `exportToPDF()` 함수:
   - `ensureLibrary('html2pdf', 'https://cdnjs.cloudflare.com/ajax/libs/html2pdf.js/0.10.1/html2pdf.bundle.min.js')`
   - 인쇄용 클래스 `body.printing` 추가 (잠시).
   - `html2pdf().from(document.querySelector('main')).set({...옵션}).save(파일명)`
   - 완료 후 `body.printing` 제거.
3. 인쇄용 CSS 추가:
   - 선택 셀의 적색 배경 → 흰색 + 굵은 검정 `✓` (잉크 절약)
   - 호버 효과·shadow 제거
   - 헤더는 한 줄만 (학교명·학과·생성일시)
   - 우측 패널을 본문 아래 박스로 재배치 (print 폭 좁아서)
   - `@page { size: A4; margin: 15mm; }`

PDF 구성:
- 상단: 학교명 + 학과명 + "생성: YYYY-MM-DD HH:mm"
- 본문: 편제표 (지정 + 선택 그룹들)
- 하단: 총 이수학점 / 교과군별 / 충족 현황

검증 단계:

1. 천안중앙고 PDF 다운로드 → 미리보기에서 학교 정보·편제표·요약 모두 표시.
2. 선택된 셀이 ✓로 인쇄용 표시.
3. A4 한 페이지를 넘기면 깔끔하게 페이지 분할되는지 확인.

### B-5-4. Excel 저장 (SheetJS 동적 로드)

수행할 작업:

1. `exportToXLSX()` 함수:
   - `ensureLibrary('XLSX', 'https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js')`
   - 3개 시트 생성:
     - **편제표**: 그룹·과목·6학기 학점·내가 선택 여부·계
     - **요약**: 총 이수학점, 창체, 교과군별 (이수/필수)
     - **선택 그룹**: 그룹별 충족 현황, 내가 선택한 과목 목록
   - `XLSX.writeFile(wb, 파일명)`로 저장.
2. 셀 스타일: SheetJS 기본 export로는 색상 지정 불가. 선택 셀은 "○" 같은 문자
   채워서 시각 구분.

검증 단계:

1. 엑셀로 다운로드 → 엑셀로 열어 3개 시트 정상.
2. 한글 깨짐 없는지 (UTF-8 BOM 처리).
3. 학점 합계가 화면과 일치하는지.
