## 1. 사전 준비 (최초 1회)

### 1-1. Python 설치

1. <https://www.python.org/downloads/> 접속 → **Download Python 3.x.x** 클릭
2. 설치 시 **"Add Python to PATH"** 체크박스를 반드시 선택한 뒤 Install

   ![Add Python to PATH 체크 필수](images/python_path.png)

3. 설치 완료 후 `명령 프롬프트`(cmd)를 열고 아래 명령어가 동작하는지 확인:
   ```
   python --version
   ```
   버전 번호가 출력되면 정상.

### 1-2. GitHub Desktop 설치

1. <https://desktop.github.com/> 에서 설치
2. GitHub 계정(`curricenterhscne`)으로 로그인
3. **File → Clone repository** → `curricenterhscne/course_selector_cne` 선택 → 로컬 경로 지정

> 이미 설치·클론되어 있으면 이 단계 건너뜀.

## 2. 편제표 수정 반영 (수시)

학교에서 편제표를 수정하거나 누락 데이터가 발견된 경우, 아래 절차를 따릅니다.

### 흐름도

```
엑셀 파일 수령  →  갱신실행.bat 실행  →  브라우저 관리 도구  →
파일 내려받기   →  data/ 폴더 덮어쓰기  →  GitHub Desktop 업로드
```

### 2-1. 엑셀 파일 준비

- 파일명 규칙: `편제표_YYYY.xlsx` (예: `편제표_2026.xlsx`)
- 파일을 프로젝트 폴더 안 `uploads/` 폴더에 복사해 두면 자동 감지됩니다.
  - 직접 올려도 되고, 브라우저에서 드래그&드롭해도 됩니다.

### 2-2. 관리 도구 실행

프로젝트 폴더에서 **`갱신실행.bat`** 를 더블클릭합니다.

- 검은색 창이 잠깐 뜨고, 브라우저에서 관리 도구가 자동으로 열립니다.
- 브라우저가 자동으로 열리지 않으면, 주소창에 직접 입력:
  ```
  http://localhost:8080/admin.html
  ```

### 2-3. 브라우저 관리 도구 조작

1. **학년도 선택**: `2025` 또는 `2026` 중 해당 연도 클릭
2. **엑셀 파일 올리기**
   - 드래그&드롭 영역에 엑셀 파일을 끌어다 놓거나
   - **파일 선택** 버튼을 눌러 파일 탐색기에서 선택
3. **처리 시작**: 파란색 **처리 시작** 버튼 클릭
4. **결과 확인**: 화면 아래쪽에 각 학교별 상태가 표시됩니다.
   - `변경됨` — 기존 파일과 내용이 달라진 학교
   - `신규` — 처음 추가된 학교
   - `동일` — 변경 없음
   - `[오류]` — 데이터 이상, 내용을 확인 후 원본 엑셀 수정 필요

   > **[오류]가 있는 경우**: 오류 내용을 복사해서 개발 담당자에게 전달하거나,
   > 원본 엑셀을 수정 후 다시 처리하세요. 오류가 있어도 나머지 학교 파일은 정상 생성됩니다.

5. **ZIP 다운로드**: 초록색 **ZIP 내려받기** 버튼 클릭 → `curricula_update_YYYYMMDD.zip` 저장

### 2-4. 파일 교체

1. 내려받은 ZIP 파일의 압축을 풀면 `data/` 폴더 구조가 나옵니다.
2. ZIP 안의 `data/` 폴더 내용을 프로젝트 폴더의 `data/` 폴더에 **덮어쓰기**합니다.
   - 탐색기에서 ZIP의 `data` → 프로젝트의 `data` 폴더로 복사·덮어쓰기

### 2-5. GitHub Desktop으로 업로드

1. GitHub Desktop 열기
2. 좌측 **Changes** 탭에 변경된 파일 목록 확인
3. 좌측 하단 **Summary** 칸에 변경 내용 간단 입력
   예: `2026 편제표 수정 반영 (○○고 3학년 선택 과목 변경)`
4. **Commit to main** 클릭
5. 상단 **Push origin** 클릭

잠시 후 사이트(<https://curricenterhscne.github.io/course_selector_cne/>)에 반영됩니다.
반영이 느리면 브라우저에서 **Ctrl+Shift+R** (강력 새로고침).

## 3. 신규 학년도 추가 (연 1회)

새 학년도 입학생 편제표를 추가할 때의 절차입니다.

### 차이점 요약

| 항목 | 수정 반영 | 신규 학년도 추가 |
|------|----------|----------------|
| 엑셀 파일 | 기존 연도 | **새 연도** 파일 |
| 학년도 버튼 | 자동 감지 | 자동 추가됨 |
| 소요 시간 | 5분 이내 | 동일 |

### 절차

2-1 ~ 2-5와 동일하나, **학년도 선택 시 새 연도 번호를 직접 입력**합니다.

> 관리 도구가 새 연도를 감지하면 자동으로 `index.html`의 연도 버튼도 추가합니다.
> ZIP 안에 `index.html`이 포함되어 있으면 프로젝트 루트에도 덮어쓰기하세요.

## 4. 문제 해결

### Python이 없다는 오류가 뜰 때

→ [1-1. Python 설치](#1-1-python-설치) 절차 수행. 설치 후 **컴퓨터를 재시작**한 뒤 다시 시도.

---

### 브라우저가 열리지 않을 때

→ 브라우저 주소창에 직접 입력:
```
http://localhost:8080/admin.html
```

---

### "포트 8080이 이미 실행 중입니다" 메시지

→ 정상입니다. 이미 서버가 켜져 있으면 브라우저만 열립니다.
만약 브라우저도 안 열리면, 컴퓨터를 재시작하거나 개발 담당자에게 문의.

---

### ZIP 다운로드 버튼이 활성화되지 않을 때

→ **처리 시작** 버튼을 먼저 눌러야 합니다. 처리가 완료된 뒤 버튼이 활성화됩니다.

---

### GitHub Desktop에서 Push 실패 시

주로 아래 두 가지 원인:

1. **인터넷 연결 문제** → 연결 확인 후 재시도
2. **로그인 만료** → GitHub Desktop 상단 알림에 따라 재인증

---

### 사이트에 변경이 반영되지 않을 때

GitHub Pages는 Push 후 최대 3~5분 소요됩니다.
시간이 지났는데도 반영 안 되면:
1. 브라우저에서 **Ctrl+Shift+R** (강력 새로고침)
2. 시크릿(인사이트) 창을 열어 확인
